# Week 02 — CSS Fundamentals & Layout

A hands-on continuation of the Full Stack Web Development course, focused on building a strong foundation in CSS and learning how to create responsive layouts and visual effects.

## Topics Covered

- CSS syntax and ways to apply CSS
- CSS selectors
- Colors and color formats
- Backgrounds
- Fonts and text styling
- Text properties and alignment
- CSS icons
- Box model
- Flexbox
- CSS Grid
- Responsive design
- CSS animations

## Projects

- Login page
- Portfolio website
- One Piece fan website

## What I Learned

By the end of Week 2, I practiced how CSS controls the appearance, spacing, alignment, layout, responsiveness, and animation of web pages.
