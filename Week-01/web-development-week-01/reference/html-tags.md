# HTML Tags Reference

A beginner-friendly reference for the HTML elements used in Week 01.

## Document and Metadata

| Tag | Purpose |
|---|---|
| `<!DOCTYPE html>` | Declares an HTML5 document |
| `<html>` | Root element |
| `<head>` | Contains page metadata |
| `<meta>` | Provides metadata such as character encoding and viewport settings |
| `<title>` | Sets the browser tab title |
| `<link>` | Connects external resources such as CSS |
| `<body>` | Contains visible page content |

## Semantic Structure

| Tag | Purpose |
|---|---|
| `<header>` | Introductory/header content |
| `<nav>` | Navigation links |
| `<main>` | Main page content |
| `<section>` | Groups related content |
| `<article>` | Independent piece of content |
| `<aside>` | Related or secondary content |
| `<footer>` | Footer information |
| `<address>` | Contact information |

## Text

`<h1>`–`<h6>`, `<p>`, `<br>`, `<hr>`, `<strong>`, `<em>`, `<mark>`, `<small>`, `<blockquote>`, `<cite>`, `<code>`, `<pre>`, `<time>`

## Lists

`<ul>`, `<ol>`, `<li>`, `<dl>`, `<dt>`, `<dd>`

## Media

`<img>`, `<figure>`, `<figcaption>`, `<audio>`, `<video>`, `<source>`, `<iframe>`

## Tables

`<table>`, `<caption>`, `<thead>`, `<tbody>`, `<tr>`, `<th>`, `<td>`

## Forms

`<form>`, `<fieldset>`, `<legend>`, `<label>`, `<input>`, `<textarea>`, `<select>`, `<option>`, `<button>`

## Interactive Elements

`<details>`, `<summary>`, `<progress>`, `<meter>`
