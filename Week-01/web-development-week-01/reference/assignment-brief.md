# Week 01 Assignment Brief

## Luffy's Grand Banquet Party

The Week 01 practical task is to build a single HTML webpage for a fictional One Piece-themed banquet.

### Main learning goals

- Build a complete HTML document.
- Use semantic HTML elements.
- Practice headings, paragraphs and text formatting.
- Create lists, tables and navigation links.
- Add images, audio, video and an iframe.
- Build a registration form with different input types.
- Use interactive elements such as `details`, `progress` and `meter`.
- Connect an external CSS file and apply basic styling.

### Personalization

- Author: **Arathana**
- Real college/contact information is intentionally not included.
- Fictional pirate contact information is used where contact details are needed.

### Note about media

The supplied Week 01 ZIP did not contain the referenced image, audio or video files. The HTML keeps the media elements because they are part of the learning exercise. Add permitted media files to the corresponding folders if you want the page to display/play them locally.
