# Week 3 — JavaScript Fundamentals

This week introduces the core concepts of JavaScript needed for frontend development.

## Topics Covered

1. Variables
2. Data Types
3. Operators
4. Input and Output
5. Conditional Statements
6. Loops
7. Functions
8. Arrays
9. Strings
10. Objects
11. Array Methods
12. Scope
13. Error Handling

## Practice

The `examples/` folder contains topic-wise JavaScript programs.

The `practice.js` file contains a progressive set of **90 practice questions**, starting from basic syntax and gradually moving toward functions, arrays, strings, objects, array methods, logic, interview-style questions, and mini-project problems.

## Assignments

The `assignments/` folder contains the weekly assignment files.

## Additional Practice

- `interview-questions.md` — JavaScript interview questions

## How to Run

Make sure Node.js is installed.

Run an example from this folder using:

```bash
node examples/01-variables.js
```

Replace the filename with the example you want to practice.
